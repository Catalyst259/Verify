# 搜索导航与状态展示修复

## 已验证原因

同一专用登录资料、相同关键词下，冷启动后直接导航搜索页会在25秒等待 DOM 加载时超时，无法读取候选。受控检查先导航主页，主页及搜索页均返回200、登录检查正常；原爬虫已有主页初始化步骤，在线来源的搜索入口此前缺少这一环节。扩大超时、处理尾斜杠或推断账号失效都没有实证依据。

`XiaohongshuSource._candidates` 现在先加载主页并检查登录/验证限制，再进入对应关键词搜索页。主页卡片不会作为该查询结果或证据。预热在原有搜索操作内完成，不额外计查询，仍受包含锁等待的120秒来源总超时限制；HTTP错误、最终笔记身份、输入排除、正文稳定性和引用校验保持。

导航失败只记录固定异常类型、页面类别、耗时及首行已知 Chromium 网络错误码。不记录异常原文、完整URL、查询词、笔记ID或签名令牌；URL内伪装的网络错误码和未知码不导出。取消继续原样传播，超时不会被当成空结果。

## 前端状态

前端依据各子图真实状态展示流程完成、部分完成、失败、跳过及尚未实现的内容，不改变后端 status 或判定。Fact completed 与 UNVERIFIED 同时出现时，明确说明流程已完成但证据不足、未能确认。默认 route/crowd/experience 尚未实现，这一范围限制不会显示成 Fact 取证中断。

地点仍只限定范围，文字、图片、链接至少一种。HTTP四字段契约不变。尚未实现的三个子图属于后续功能开发，本修复没有生成虚假完成状态。
