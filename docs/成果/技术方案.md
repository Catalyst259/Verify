# 技术方案

## 图片请求链路
1. 前端用户拖拽图片至上传框，这个接口只传文件
POST /api/files
Content-Type: multipart/form-data
```TypeScript
const formData = new FormData()
formData.append("file", file)
const response = await fetch("/api/files", {
  method: "POST",
  body: formData
})
```
2. 后端接收文件，生成唯一ID与对象存储KEY，存储到对象存储，并在数据表"files"中记录文件信息，返回文件ID给前端，同一会话 order 自动加一
```json
{
  "file_code": "file_01K7ABC",
  "mime_type": "image/jpeg"
}
```
3. 前端创建核验任务
POST /api/verifications
Content-Type: application/json
> 作为文件上传时，这里的 content 字段传入文件 ID
```json
{
  "target_place": "上海迪士尼乐园",
  "image": ["file_01K7ABC"]
}
```

## 材料标准化
1. 前端创建核验任务
POST /api/verifications
Content-Type: application/json
请求DTO：
```json
{
  "target_place": "上海迪士尼乐园",
  "text": "动物很多，适合亲子游",
  "link": ["https://www.google.com.hk/"],
  "image": ["file_01K7ABC"]
}
```
2. 并行图片提取，后端使用 file_code 获取 OSS object_key，获取 bytes 或临时签名 URL,最后按顺序注入到 multimodal model 中
```python
def FileExtractor(file_code: str) -> bytes:
    # 1. 根据 file_code 查询数据库，获取 object_key
    # 2. 调用对象存储服务，获取文件 bytes
    return file_bytes
```
3. 把地点，图片，文字，链接等信息注入 multimodal model 中，提取与目标地点相关的 Claim，用 browser-use

```python
class ExtractedImage:
    file_code: str
    mime_type: str
    data: bytes

async def extract_file(file_code: str) -> ExtractedImage:
    file = await file_repository.find(file_code)

    data = await oss.get_object(file.object_key)

    return ExtractedImage(
        file_code=file_code,
        mime_type=file.mime_type,
        data=data,
    )

```

可以：
✓ 打开用户提交的 link
✓ 翻页/展开正文
✓ 看网页图片
✓ 看用户上传的图片

不可以：
✗ 搜索这个地点
✗ 打开搜索引擎寻找额外信息
✗ 用外部证据判断真假
