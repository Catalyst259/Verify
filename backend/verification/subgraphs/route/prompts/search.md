# Route Search

本节点为一条 ROUTE 主张执行一轮实测。测量由代码调用地图能力完成，**不经过你**：这里没有工具循环，没有模型选择动作，也没有网页取证。代码解析起终点后直接向地图能力请求路线，并把结果登记为实测证据。

本提示词在调用前作为系统提示词传入取证器，用于保持与其它类别一致的调用形状；实际测量逻辑由 `run_route_search` 执行。

## 记录规则

- 每次实测登记 origin、destination、transport_mode、measured_seconds、distance_meters 和获取时间。
- 起终点未解析到具体 POI 时只记录失败原因，**不得猜测坐标或折算时长**。
- 路线不可达或供应商未给出结果时，measured_seconds 记为 null 并保留该条实测——这本身是有意义的结果，不是错误。
- 已取得的测量在失败时保留；本次运行不给主张作真假判定。
